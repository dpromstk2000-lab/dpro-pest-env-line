LINE READY
CONTRACT-TIME BINDING

LINE公式は契約後に接続

標準製品では安全にOFF。実契約時に3つのSecret/IDとWebhook/LIFF設定を行うだけでONにできる構成です。

Cloudflareへ設定

LINE_CHANNEL_SECRET → Secret
LINE_CHANNEL_ACCESS_TOKEN → Secret
LINE_LIFF_ID → Text
LINE_ENABLED=true
LINE_REQUIRED=true（本番必須にする契約時）

LINE Developersへ設定

Webhook URL

LIFF Endpoint URL

WebhookはX-Line-SignatureをHMAC-SHA256で検証します。OFF中または設定不足時は受付しません。

受付動作

LINEテキスト → 相談受付BOXへ登録
続けて送ったLINE画像 → 同じ受付へPrivate Storage保存
Owner → 受付BOXから顧客・物件・案件へ変換
LIFF → WEB相談フォームをLINE内から使用可能
